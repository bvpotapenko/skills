## Shortcuts — reuse solved problems
Shortcut files live at ~/.kerminal/projects/{project}/shortcuts/{task_family}.md (one file per recurring task family). Entry format and hygiene: see the `shortcuts` skill.
- Before starting any non-trivial task, check the project's shortcuts/ directory for a matching file and read it first — applying a known fix beats rediscovering it.
- The moment you abandon an approach (or an error has cost ~15 min), append the dead end to the matching shortcut file immediately — one line: what you tried and why it failed. Never postpone to session end.
- When the problem is solved, append the working fix to the same entry: exact commands, exact versions, one-sentence reason it works, and the time cost ("~2h wasted -> next time 5 min").
- If the same lesson appears in shortcut files of 2+ projects, propose promoting it to this AGENTS.md as a global rule.
